# 设计参考与实现取舍

研究日期：2026-10-10。

参考来源为 [Joye 的个人网站](https://www.joyehuang.me/)、[joyehuang/blog 仓库](https://github.com/joyehuang/blog) 与仓库中的 [DESIGN.md](https://github.com/joyehuang/blog/blob/main/DESIGN.md)。先观察页面与设计约定，再从干净的 Astro Starter 构建 JinVx；没有导入该参考项目的完整模板。

## 参考中值得保留的原则

- 导航低噪，正文与项目是主要内容，界面不抢占阅读注意力。
- 留白充足，标题、正文、技术标签和元数据形成清晰层级。
- Blog、Notes 与 Projects 各有入口，长文章和零散笔记不混为一个内容流。
- 深浅主题都保持阅读对比度，技术感可以由等宽标签与细节表达。

参考仓库的设计说明强调安静的编辑式阅读体验，同时将终端与吉祥物层作为单独的趣味体验。JinVx 第一版只吸收前者的内容组织原则，优先保持轻量。

## JinVx 自己的表达

| 方向 | JinVx 的选择                                                      |
| ---- | ----------------------------------------------------------------- |
| 色彩 | 蓝色纵向渐变与天蓝色交互强调                                      |
| 排版 | 系统字体保证中文阅读，等宽字体用于技术标签与代码                  |
| 首页 | 居中头像与名字，简介及 Personal Agent 文字介绍，Blog / Notes 列表 |
| 项目 | 独立原创项目卡片与规划流程视觉，说明状态与范围                    |
| 内容 | Markdown 为主，MDX 只在需要提示块等组件时使用                     |
| 维护 | 个人信息和导航集中配置，静态生成，少量客户端交互                  |

页面布局、组件、样式与演示文字均为本项目独立编写。不复制参考作者的履历、项目成果、文章、照片、头像、吉祥物或其他私人素材，也不使用远程字体与参考作者的图像资源。

后续阅读样式参考了用户指定的 [文章页面](https://www.joyehuang.me/blog/20261006---soareview/post) 和导航截图：顶部导航融入背景，滚动后收成圆角浮层；暗色文章采用炭灰表面和轻微边框，避免提示块抢占正文注意力。交互与样式在本项目独立实现，不引入动画依赖。
