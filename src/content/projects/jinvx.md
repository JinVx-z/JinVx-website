> 更新于 2026-10-22。你正在浏览的就是这个项目：网站已上线，内容与界面会随着我的开发和学习持续更新。

## 一个持续记录的地方

我希望有一个自己的地方，把正在做的项目和过程中的思考放在一起。它既是个人主页，也是持续生长的开发记录：项目页说明作品解决什么问题、目前做到哪里，文章和笔记保留实现过程、学习收获与尚未想清楚的问题。

目前重点记录 [Personal Agent](/projects/personal-agent/) 的开发。相比只展示一个最终成果，我更希望把实际进展、验证结果和后续方向说清楚，让网站随着项目一起成长。

## 已经上线的内容与功能

- **Home / About**：介绍自己、当前关注的方向，以及公开的 GitHub 入口。
- **Projects**：项目卡片与独立详情页，展示实际状态、技术栈、开发进展及相关链接。
- **Blog / Notes**：分别承载整理后的开发文章与学习思考，支持 Markdown、MDX 和代码高亮。
- **阅读与导航**：提供浅色、深色主题切换，适配手机的导航菜单与页面布局，以及文章和笔记的 RSS 订阅。

## 技术选择：让写作和维护保持轻量

网站使用 Astro、TypeScript 和 Tailwind CSS，构建为静态页面，少量客户端脚本负责主题和导航交互。文章、笔记和项目介绍都保存在仓库的 Markdown / MDX 文件中，通过内容集合校验元数据，再由统一布局生成页面。

这种方式让我可以直接在熟悉的编辑器里更新内容，用 Git 记录变化，不必额外维护数据库、登录系统或 CMS。页面沿用蓝灰色视觉、简洁排版与等宽技术标签，把主要空间留给项目和文字。

## 从修改到发布

代码托管在 GitHub，站点部署在 Vercel。每次更新先检查内容与差异，运行 `npm run verify`，完成 Astro 检查、生产构建，以及页面标题、链接、资源、RSS 和站点地图等输出校验，再提交并推送，由 Vercel 构建发布。

检查通过后还会打开实际页面核对展示；涉及布局的调整，再检查对应的桌面或手机视口。发布成功与内容是否准确分别确认，让维护过程有可核对的结果。

## 接下来继续做什么

持续同步 Personal Agent 的实际进展，补充开发文章和学习笔记，并在日常使用中打磨阅读与导航体验。新功能围绕真实需要增加，先把内容写清楚、把现有页面维护好。
